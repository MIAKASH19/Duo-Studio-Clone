🎨 Duo – Studio (Agency Website Clone)

Duo – Studio is a modern agency website clone created to practice and enhance frontend development skills. This project focuses on building a visually appealing UI, smooth animations, and a fully responsive layout, inspired by real-world creative agency websites.

The goal of this project is to improve UI accuracy, animation flow, and component structuring using modern frontend technologies.

To run this project locally:

# Go to the project directory

# Install dependencies
npm install

# Start the development server
